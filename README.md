# StreamBox — Live TV, Radio & Podcasts

A single-file mobile web app for watching free live TV, listening to Indian radio, and playing podcasts. No account, no server, no build step — everything runs in the browser and your data stays on the device.

**Live:** https://deepkandoi.github.io/IPTV_app/  
_(served from the `streambox` branch — the original Express app on `main` is untouched)_

## What's inside

- **271 India TV channels** and **149 radio stations** preloaded, with real logos where available
- **Playlists:** M3U/M3U8, Xtream Codes (live + movies + series), JSON collections, PLS, ASX, XSPF, pasted text and local files
- **Playback:** HLS, MPEG-DASH, MPEG-TS, MP4/WebM and audio — with automatic failover across duplicate URLs, engine switching and dead-channel skipping
- **TV guide:** XMLTV (including gzipped), a timeline grid, catch-up playback and programme reminders
- **Player:** speed, resume, quality lock, episode overlay, gestures, subtitles (embedded or a local .srt), audio-only, PiP, sleep timer
- **Library:** favourites, recents, hidden channels, custom channel numbers and your own groups
- **Interface:** grid / live-thumbnail / list layouts, dark-AMOLED-light themes, 8 accents, compact density, accessibility mode, and a Hindi UI

## Install on your phone

Open the live link, then use the browser menu → **Add to Home screen**. It installs as a standalone app.
